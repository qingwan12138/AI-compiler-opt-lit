# Learning to Optimize 文献阅读总结

论文题目：**Learning to Optimize Tensor Programs**
作者：Tianqi Chen, Lianmin Zheng, Eddie Yan, Ziheng Jiang, Thierry Moreau, Luis Ceze, Carlos Guestrin, Arvind Krishnamurthy
发表时间：2018
发表平台：NeurIPS 2018
元数据核验来源：[NeurIPS 2018 论文页](https://papers.neurips.cc/paper/7599-learning-to-optimize-tensor-programs)；[arXiv](https://arxiv.org/abs/1805.08166)
代码/数据/工件：[Apache TVM（AutoTVM / tensor-program optimization implementation）](https://github.com/apache/tvm)
论文链接或编号：NeurIPS 2018
关键词：张量程序优化；学习型代价模型；迁移学习；自动调优

> 本文档用于文献阅读、组会汇报和后续研究分析。

---

## 1. 研究背景

张量程序的优化搜索空间包含数十亿甚至更多的实现变体（不同循环分块大小、展开因子、内存布局等组合），手动枚举和专家调优的方式已无法应对硬件快速演进的局面。手工编写的优化库只能覆盖少数主流硬件配置，已有的自动搜索方法需要在目标硬件上进行大量真实测量才能收敛到高性能配置，调优成本高昂。

## 2. 论文要解决的问题

### 2.1 如何减少张量程序搜索所需的硬件测量次数
传统搜索方法（如模拟退火）需要大量硬件测量才能收敛。能否通过学习一个统计代价模型来显著减少测量次数？

### 2.2 如何利用历史搜索经验加速新任务的优化
能否利用以往workload和硬件平台上的搜索经验通过迁移学习来加速新任务的优化？

## 3. 核心方法概述

本文提出一种基于学习的张量程序优化框架，核心思想是使用一个领域特定的统计代价模型（domain-specific statistical cost model）来预测候选调度的性能。

```
历史测量数据 --> [特征工程] --> [统计代价模型训练]
                                       |
新任务张量程序 --> [调度空间枚举] --> [代价模型预测]
                                       |
             高置信度候选 --> [真实硬件验证] --> [更新训练数据]
                                       |
                              最优调度 --> 目标代码生成
```

## 4. 实验框架与系统执行流程

探索模块（exploration module）利用代价模型的预测来指导新程序变体的生成和筛选。迁移学习将从已有workload和硬件上收集的测量知识迁移到新任务上。整个框架构建在TVM的调度抽象之上，通过迭代的"预测-测量-更新"循环不断改进搜索效率。不确定性驱动的探索策略（UCB、Thompson Sampling等）在利用已有知识和探索未知区域之间动态平衡。

## 5. 奖励函数、损失函数或关键公式

本文没有使用强化学习。代价模型的训练目标是预测调度配置的性能（如延迟），使用回归损失函数（如均方误差）进行优化。

## 6. 实验设置

### 6.1 数据集
主流卷积神经网络（ResNet、VGG、MobileNet、Inception等）中的典型算子。

### 6.2 模型与工具
统计代价模型（特征嵌入 + 回归）、迁移学习框架。

### 6.3 对比方法
无迁移的从头搜索、随机搜索、模拟退火搜索。

### 6.4 评价指标
达到目标性能所需的硬件测量次数（样本效率）、最终算子吞吐量（GFLOPS）相对于工优化库基线的性能比例。

## 7. 实验结果与结论

### 7.1 主要结果
学习型代价模型相比无模型搜索方法，在达到相同性能水平时硬件测量次数降低约5到10倍。最终性能可接近甚至超过手工优化库的水平。

### 7.2 消融实验
迁移学习效果显著：新workload的调优成本降低约40%到60%。跨硬件迁移效果较弱，表明代价模型知识具有较强硬件特定性。基于不确定性的策略（UCB和Thompson Sampling）优于随机策略。

### 7.3 案例分析
迁移学习中"共享代价模型层加微调特定层"的架构为后续跨平台知识共享提供了参考。

## 8. 主要创新点

### 8.1 首次将学习型统计代价模型系统引入张量程序自动调优
开创了以数据驱动替代手工启发式的研究范式，取代了传统基于分析模型的启发式搜索方法。

### 8.2 提出了在代价模型框架内实现迁移学习的技术方案
利用多个历史workload的测量数据来初始化新任务的模型，显著降低了冷启动成本。设计了不确定性感知的探索策略和"预测-验证"混合搜索闭环。

## 9. 局限性

**论文承认的局限：** 方法面向张量程序调度搜索，搜索空间依赖TVM的调度原语，不适用于通用编译器IR层面的Pass选择。跨硬件迁移收益有限。

**阅读后发现的局限：** 代价模型预测准确性受限于训练数据覆盖范围。迁移的单位是调度配置和模型参数本身，而非可解释的优化知识。每增加新硬件平台仍需收集相当规模的测量数据。缺乏对失败案例的系统分析。

## 10. 阅读后的研究方向反思

本文是"多平台快速适应"场景下的经典强基线。不确定性驱动的搜索策略（UCB、Thompson Sampling）对有限查询预算下选择最优候选具有直接参考价值。代价模型只提供性能预测分数而不提供诊断性反馈，而跨架构迁移研究中若能输出失败原因分析将比传统代价模型更具优势。

## 11. 可进一步尝试的研究方向

**研究问题：** 如何将代价模型与诊断性反馈结合，不仅预测性能还解释性能瓶颈？

**区别与创新：** 在代价模型输出性能分数的同时，增加瓶颈分类输出（如寄存器溢出、访存瓶颈、指令流水线停顿），为优化决策提供更丰富的信号。

**风险：** 诊断信息的标注成本高，瓶颈分类的准确性依赖微架构知识。

**框架：** 代价模型 --> 性能预测 + 瓶颈诊断 --> 优化决策 --> 硬件验证 --> 反馈闭环。

## 12. 与其他已读文献的关系

本文是TVM（2018）中代价模型方法的扩展和理论化。Ansor（2020）在此基础上增加了自动搜索空间生成和进化搜索。Learning to Optimize的"训练-预测-验证"范式与CompilerGPT的反馈驱动优化思路类似，但CompilerGPT使用LLM和编译器诊断报告而非统计代价模型。

## 13. 一页式总结

| 项目 | 内容 |
|------|------|
| 论文题目 | Learning to Optimize Tensor Programs |
| 发表平台 | NeurIPS 2018 |
| 核心贡献 | 学习型统计代价模型 + 迁移学习驱动的张量程序优化 |
| 核心方法 | 特征工程 + 代价模型 + 不确定性驱动的探索策略 |
| 关键发现 | 硬件测量次数降低5-10倍，跨workload迁移成本降低40-60% |
| 主要局限 | 限于张量程序调度搜索，跨硬件迁移知识有限 |
| 与后续工作关系 | TVM代价模型的扩展，Ansor/CrossTune-RL的方法论基础 |

本文通过学习型统计代价模型显著减少了张量程序搜索所需的硬件测量成本，并证明了迁移学习对跨workload加速的有效性。其跨硬件迁移能力有限且不处理通用IR优化的局限，恰好为CrossTune-RL等探索通用编译器优化方案的研究提供了方法边界和性能标杆。
