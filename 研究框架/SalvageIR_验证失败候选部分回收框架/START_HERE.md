# 服务器从这里开始

> salvageir_v3 · 本文件夹可以整体复制、改名或解压到任意服务器目录。

可选：在解压后的文件夹根目录运行 `sha256sum -c SHA256SUMS`，核对文件传输完整性。
若是合并到旧目录，请先备份旧规范，并保留旧代码、数据和日志；旧run沿用旧协议标签，不与v3结果混算。

只需把下面这句话发给服务器上的 Codex：

> 请阅读当前文件夹的README.md和CODEX_P0A_EXECUTION_HANDOFF.md，按其中列出的v3规范开始P0a。先检查已有代码、工具和32条实验记录，保留全部旧文件；实现并运行必要的最小审计和测试。不要自动启动新一轮GPU生成、大型下载或RISC-V实验。缺少原始数据时先完成其余可做任务，再列出具体缺件，不要编造实验结果。

注意：

- 这是研究规范＋实施工单，不是已经实现好的实验软件；工单中的CLI是待实现/适配接口。
- 不需要本地文献语料库、C盘路径、ARIS项目或原对话记录；联网文献链接仅供查证，不是启动依赖。
- 优先使用服务器上已有实现和LLVM/Alive2。缺工具时Codex应说明安装需求，不能将mock当集成测试。
- 已有32条输出、对应源IR、模型原始输出、Alive2日志和当时配置是用户实验资产，不包含在这份文档包里；放在服务器可读目录并告诉Codex路径即可。
- 当前规范是根目录v3文件。archive/v2仅为历史追溯，禁止按旧版工单执行。
- 所有新运行放experiment/或已存在的等价工作区，不能覆盖旧日志。
- 本地打包不会自动同步服务器；每次更新须重新复制，并由Codex记录规范哈希。
