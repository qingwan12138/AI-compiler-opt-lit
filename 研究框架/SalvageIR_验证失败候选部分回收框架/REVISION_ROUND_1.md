# SalvageIR 第一轮修订追踪

> 本文件不替代 [`REVIEW_ROUND_1.md`](REVIEW_ROUND_1.md)。原始拒稿意见永久保留；本文件记录每项意见如何改变研究设计。

| 审稿问题 | 修订动作 | 通过证据 | 失败时降级 |
|---|---|---|---|
| C1，退化为 ddmin | 新增 RCES 问题定义；加入结构化 ddmin、CE-hitting-set/MaxSAT、SandboxIR 事务基线 | 预算曲线下 M 优于全部强结构基线 | 删除反例算法贡献 |
| C2，反例不可定位 | 增加三态 CE adapter、稳定重放、覆盖门与安慰剂反例 | `CE_LOCALIZABLE` 覆盖和 real-vs-shuffled 差异 | 只称结构化回滚 |
| C3，模型目标错配 | Track B 改用 base/instruct checkpoint；SFT 只在 Track A | 模型锁和训练目标审计 | 目标错配模型不进主结果 |
| C4，RISC-V 跨目标无效 | 仅从同一源独立生成 RV64GC IR；分开 frozen-decision 与 rerun | 每目标独立 refinement 和端到端回退 | 只报告可编译案例 |
| M1，首个安全盆地偏差 | 维护 `k_safe` 非支配安全前沿 | 与 oracle 的 regret 和前沿覆盖 | 声明启发式而非近最优 |
| M2，评分可调 | 冻结无训练评分式和稳定 tie-break | 配置哈希、消融 | 学习排序只作附录 |
| M3，虚假 gold | provenance 单元集测精确恢复；自然集只测一致性 | exact recovery + kappa + 不变量 | 停止复杂 Tier |
| M4，oracle 选择偏差 | `n>12` 固定预算 witness 下界；确认集复核现象 | oracle 率 + all-pool 保守下界 | 只主张小组件范围 |
| M5，`-Oz` 管线存疑 | 加 `clang -Oz` 校准门、属性与 TargetMachine 锁 | 抽取/参考机器码一致 | 不能声称 code-size |
| M6/M7，数据与统计 | D-C 改 24×10；区分均衡 estimand；增加 jackknife/随机化 | 多种区间方向一致 | 只作描述性结果 |
| M8，LLM 必要性 | 加编辑规模匹配的非 LLM 负对照 | LLM 候选结构显著不同或方法交互 | 改投通用 IR repair |
| M9，预算挑选 | 16–256 calls 性能剖面与 AUC | 多预算稳定优势 | 只报告成本—效果边界 |
| M10，抽取语境 | context-preserving harness 和模块/抽取校准 | 两条编译路径一致 | 排除并报告不闭合样本 |

## 修订后的投稿门

不再用一个综合成功率把论文“抬过线”。正式论文必须分别通过：

- **F 门：**现象真实且不依赖目标错配；
- **I 门：**反例相对安慰剂和强结构搜索有识别性贡献；
- **S 门：**函数级机器码收益能在端到端二进制和独立 RV64GC 流水线上留下非零效果。

只通过 F：可写失败候选测量论文；通过 F+I：可写方法论文；F+I+S 全通过才主张实用 Translator 后处理框架。

## 修订后模拟评分

这是对研究设计的评分，不是对尚不存在的实验结果评分：

| 维度 | 修订前 | 修订后暂评 | 仍缺什么 |
|---|---:|---:|---|
| 问题重要性 | 7/10 | 7/10 | 真实失败规模 |
| 新颖性可辨识度 | 5/10 | 6.5/10 | real CE 必须胜 shuffled CE 与 B5/B6/B7 |
| 方法严谨性 | 5/10 | 8/10 | 实现反例适配器和安全前沿 |
| 实验设计 | 6/10 | 8/10 | 运行 F/I/S 门并达到样本量 |
| 可复现性 | 6/10 | 8/10 | 锁定模型、工具、数据和容器实物 |
| 当前可投稿性 | 4/10 | 6.5/10 | 尚无 P0/P1 数据，不能视为可投稿论文 |

若 F、I、S1 全通过，设计层面可升到约 8/10；若 I2 失败，即使恢复率好看，也应降回约 5.5/10 的结构化回滚工具论文。
