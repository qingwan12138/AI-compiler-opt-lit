# SalvageIR 研究契约

> salvageir_v3 · 2026-09-21 · 当前研究边界的最高优先级文件。

## 1. 对象与角色

源函数 S 是语义规范，T0 是 LLM 生成的完整优化候选。
主恢复任务只处理 LLVM parser/verifier 通过、接口不变、被冻结 Alive2 明确 REFUTED 的候选。
UNKNOWN、语法错误、工具崩溃不是语义反例；初始正确候选不进入恢复任务。

研究属于 Translator/T2：IR 到优化 IR 的实例转换。验证、确定性搜索和后端测量是 Supporting。
不选择 pass 序列、不生成可复用规则、不开展任务特定训练或 RL。
核心恢复中不得新增 LLM 调用；整函数重试只作为独立、计费的比较基线。

## 2. 输入与主评价

主输入 PRE_SSA：由有出处的未优化 raw IR，经声明的属性处理、mem2reg 和非语义规范化生成。
不得把 mem2reg 描述为纯格式清理；不删除 lifetime、poison/undef/freeze 或语义 flag 来便利验证。
POST_OZ：同源 PRE_SSA 的固定 Oz 输出，单独报告；历史 post-Oz 候选不得伪装为 PRE_SSA。

定义 P 为锁定的默认 Oz 流水线，C 为锁定 x86-64 后端的函数符号机器码字节。
原始代码到 raw IR 依赖前端可信边界；raw→S 及 S→P(S) 的验收见预实验协议。
主终点是 C(P(R)) 相对 C(P(S))，不是相对错误 T0，也不是只与 O0 比较。

## 3. 有益回收的全部条件

1. R 来自冻结编辑表示中的严格子集：非 all-source、非 all-target，且规范化内容不等于 S/T0。
2. LLVMVerify(R) 通过，直接 Alive2(S,R)=VERIFIED。
3. 最终交付的 P(R) 也通过 LLVMVerify 和直接 Alive2(S,P(R))=VERIFIED。
4. C(P(S))−C(P(R)) ≥ max(2 bytes, ceil(0.01×C(P(S))))。
5. 同一 context harness 的 allocatable 非 BSS 字节不增加。
6. 所有状态、验证和精确成本在预算内完成，原始记录齐全。

VERIFIED 指所锁定工具语义及支持范围内的 refinement 裁决，不声称无条件数学等价或机器码完整证明。
测试仅补充，不能升级 UNKNOWN。源级 UB 不能由 Alive2(S,S) 排除。
没有上述结果则部署时回退 P(S)，收益记零；回退不是回收成功。
严禁以去掉最终验证、降低成功阈值或混入合成样本换取通过。

## 4. 表示边界

结构硬约束只表达构造所需条件；语义风险关联用于排序，不能凭依赖关系宣称组件正确或独立。
整函数验证通过的是某个完整状态，不授予其中的组件在其他上下文中“已证明正确”的资格。
重放不得发明新计算、常量、控制流或修复代码；只允许确定性重命名及已有两端实体的合法连接。
若需要新 PHI、桥接表达式或额外变换才能接合，标记超出严格子集表示，不静默合成。

P0 核心语言是无循环、无内存/指针/调用、标量整数的过程内函数，详细白名单见预实验协议。
P0 builder 首先支持单块/固定 CFG；不支持的对齐或大规模 CFG 改写必须保留为覆盖失败。
语言范围符合而表示失败的 REFUTED 候选，仍留在条件恢复率分母。
内存、浮点、向量、循环、跨过程是未来版本，不以图中列出 MemorySSA 就声称已支持。

## 5. 三层待检验主张

- H1 现象：自然失败候选中存在可验证且 post-Oz 有益的严格子集。
- H2 表示：结构重放能覆盖人工审计确认的非平凡子集，而非因过度合并抹去机会。
- H3 搜索：反例提供超出静态关联的信息，在等候选/资源下优于强结构搜索。

H1 的存在案例不是普遍发生率；H2/H3 需要冻结数据上的对照。
不预先宣称“高分框架”“首次”“近最优”或“必然提高成功率”。

## 6. 公平性与统计

每个搜索方法共享完全相同的 S、T0、编辑表示、成本函数和验证配置。
表示消融另列，不能与纯搜索比较混淆。计入图构建、反例物化、全部验证、Oz、代码生成时间。
全部生成漏斗、全部 REFUTED、核心范围 REFUTED、模型分层结果及端到端结果必须同时保留。
多个输出/模型/输入设置来自同一源函数，不是独立程序样本；按项目及近重复家族聚类。
失败与 UNKNOWN 在方法成功率中计未成功，不从分母消失。

## 7. 研究决策和外部验证

先 P0a 已有样本与基础设施，再固定规模 P0b 可行性，之后才冻结正式确认实验。
工程 smoke 失败暂停受影响路径；样本不足表示证据不足，不推断问题不存在。
oracle 只覆盖构造出的表示空间，未完成搜索不产生不存在结论。
反例机制无优势就删除该贡献；收益只存在于 Oz 前就删除 post-Oz 优化收益主张。

RISC-V 只在方法冻结后，从同一源代码独立生成 RV64GC IR 并重新验证。
默认测冻结算法重跑，不要求编辑掩码迁移；不把改 triple 当迁移。
仅有正例只能主张存在性；总体改善需预定程序集的全分母结果。
RISC-V 无提升意味着用户要求尚未达成，不能倒逼主方法事后调参。

## 8. 当前完成边界

本文件是设计，不是结果。P0a 可以在仅有此文件夹的 AutoDL 环境实现。
ARIS 若可用仅辅助记录/运行/审计，不是依赖；其他项目和旧运行不被覆盖。
未访问用户远端日志、未执行集成测试时必须明确说明。
